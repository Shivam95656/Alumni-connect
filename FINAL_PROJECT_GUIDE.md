## 🚀 HOW TO USE (5-Minute Startup)

### Step 1: Start Backend
```bash
cd "d:\project\Alumni connect\backend"
npm start

# You should see:
# Alumni Connect API running on port 5000
```

### Step 2: Open Landing Page
```
Open in browser:
d:\project\Alumni connect\index_final.html

OR use a local server if preferred
```

### Step 3: Navigate the Platform
```
From Landing Page:
├─ Click "Join as Alumni" 
│  └─ alumni/login_final.html
│     ├─ Register OR Login
│     └─ Opens alumni/dashboard_final.html
│
├─ Click "Admin Panel"
│  └─ admin/login_final.html
│     ├─ Register OR Login
│     └─ Opens admin/dashboard_final.html
│
└─ Click Home Button:
   └─ Returns to index_final.html (from any login page)
```

### Step 4: Try Key Features

**As Alumni:**
1. Go to "Opportunities" tab
2. Browse Internships & Placements
3. Click "🚀 Apply Now" button
4. Fill the application form
5. Submit application
6. Check "My Applications" section

**As Admin:**
1. Go to "Opportunities" tab
2. Create events, internships, placements
3. Go to "Approvals" tab
4. Approve/Reject pending alumni
5. Search alumni by filters
